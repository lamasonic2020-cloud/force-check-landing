# Force Check — ACUFLOW landing page

Static lead-magnet landing page for the Force Check, a free 16-question
self-assessment for RMTs and hands-on therapists.

- `index.html` — landing page (two signup forms)
- `thank-you.html` — post-signup page
- `style.css` — ACUFLOW brand tokens + responsive layout
- `config.js` — **the only file you edit**: Google Form id + field ids
- `app.js` — validation, submission, follow-up question
- `SETUP.md` — full setup, hosting and hand-over notes

Names and emails are posted straight to a Google Form, so the page keeps its
own design while Google Forms collects the list.
